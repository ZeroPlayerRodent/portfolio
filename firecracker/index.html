Firecracker Game Engine

Firecracker is a game engine for creating arcade-action games on the Commodore 64 home computer.

Here is a list of basic features Firecracker provides to the developer:

  • A scripting language with Lisp-like syntax
  • Inline sprite editing
  • Software sprite collision detection
  • Built-in 6 digit scoreboards
  • Compilation to human-readable assembly

Firecracker's compiler is written in Common Lisp, and its scripting language has Lisp-inspired syntax.

Despite the syntax bearing a resemblance to Common Lisp, the scripting language functions more similarly to something like FORTRAN or BASIC.

The engine is developed with ease of use and code size in mind, and is powerful enough to allow a programmer to write a full game in under 1000 lines of code.

The scripting language also compiles to human-readable assembly instead of pure binary, so an experienced developer may edit and expand upon the compiler output themselves.

By default, Firecracker games are loaded into the C64's cartridge memory and are therefore 8 kilobytes or less. This allows developers to easily write games for cartridge, disk, or tape storage formats.
